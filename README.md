# 📊 Excel Sales Dashboard

## 📌 Project Overview
This project is an interactive **Sales Dashboard built using Microsoft Excel** to analyze sales performance and generate meaningful business insights. It provides a visual representation of sales data across different products, salespersons, regions, and months.

The dashboard helps users understand sales trends, identify top-performing salespersons and products, and compare regional performance.

## 🎯 Project Objectives
- Analyze overall sales performance.
- Identify the highest-performing salesperson.
- Compare product-wise sales and profit margins.
- Analyze region-wise sales performance.
- Track monthly sales trends.
- Monitor total quantity sold and sales amount.
- Present business insights through interactive charts and visualizations.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Charts & Data Visualization
- Dashboard Design

## 📂 Workbook Structure

The Excel workbook contains three sheets:

1. **Dashboard:** Visual representation of sales performance using KPIs and charts.
2. **Pivot Tables:** Summarized sales information by salesperson, product, region, and month.
3. **Class (Raw Data):** Source sales data containing dates, regions, salespersons, products, quantities, sales amounts, discounts, and profit margins.

## 📈 Key Performance Indicators (KPIs)
The dashboard highlights:
- Highest Sales
- Best Salesperson
- Best Sales Month
- Best Performing Region
- Total Quantity Sold
- Highest Profit Margin by Product
- Highest Profit Margin by Person
